Privacy Policy

Effective: September 21, 2026

What this app does

Shorts Uploader is a personal automation tool. With the owner's permission via Google OAuth, it uses the YouTube Data API (youtube.upload scope) for one purpose only: uploading generated videos as YouTube Shorts to the owner's own YouTube channel.

Data collection and use

The app does not collect, store, or share personal data about anyone. The only credentials involved are the owner's own Google OAuth tokens, which are stored privately on the owner's own server and used solely to perform the uploads described above. No data is sold, shared with third parties, or used for advertising. There are no other users.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately stops the app from uploading.
